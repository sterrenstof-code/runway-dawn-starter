# Figma Review Checklist
## Wat controleer je in Figma vóór je begint?

Gebruik in **Dev Mode** (`development-team@beyondesign.io`).
Alles hieronder uitvoeren **vóór** de eerste regel code.

---

## ✅ 1. Toegang & Dev Notes

- [ ] Toegang tot Figma Dev Mode?
- [ ] Alle dev notes gelezen en begrepen?
- [ ] Twijfel? → **Stop, vraag de PM**

---

## ✅ 2. Wat is dynamisch?

### Metafields (per product/collectie)
- [ ] Subtitels, badges of labels naast de standaard titel?
- [ ] Extra afbeeldingen per product?
- [ ] Video's of extra media?
- [ ] Subheadings, USP-teksten per product?
- [ ] PDP-tabs (maten, ingrediënten, specs)?
- [ ] Promotionele badges op productkaarten?

### Metaobjects (herhalende structuur)
- [ ] Testimonials (naam, quote, foto, rating)?
- [ ] USP-kaarten (icoon, titel, beschrijving)?
- [ ] FAQ-items (vraag + antwoord)?
- [ ] Teamleden (naam, functie, foto)?
- [ ] Andere kaartstructuren met 2+ velden?

> **Vuistregel:** meerdere instanties van dezelfde structuur → metaobject

### Section settings
- [ ] Headings/subheadings per sectie?
- [ ] CTA-tekst en URL?
- [ ] Kleurschema per sectie?
- [ ] Achtergrondafbeelding of video?
- [ ] Max aantal items?

### Theme settings (globaal)
- [ ] Brandkleuren, lettertypen, logo?
- [ ] Announcementbar-tekst?
- [ ] Social media links?

### App-managed
- [ ] Reviews (Okendo, Judge.me, Yotpo)?
- [ ] Subscriptions, Loyalty, Translations?

## Deliverables na Figma review

Klaar voor je begint:

1. **Secties-inventaris** — bouwvolgorde
2. **Metafield-lijst** — naam, type, owner, sectie
3. **Metaobject-lijst** — definitie + velden
4. **Token-overzicht** — kleuren, fonts, spacing uit Dev Mode
5. **Asset-lijst** — te exporteren bestanden + naamgeving
6. **Vragen voor PM**
